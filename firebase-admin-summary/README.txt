CONTROL DE PRESENCIA - RESUMEN DIARIO FIREBASE

1. Subir la carpeta firebase-admin-summary, conservando index.html, a la raíz del repositorio GitHub control-presencia-pages.
2. Abrir https://angelgranadosmartinez-spec.github.io/control-presencia-pages/firebase-admin-summary/
3. Entrar con el administrador de Firebase.
4. Consultar resumen de trabajadores activos, presentes y pendientes.

La página solo realiza lecturas. Utiliza el día UTC, igual que el fichaje de prueba.
Mantener Supabase y la web actual sin cambios. No introducir datos reales hasta finalizar pruebas y autorizaciones.
